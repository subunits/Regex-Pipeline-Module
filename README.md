
# Regex Pipeline Module

This TypeScript module provides:

- Sync & Async regex pipelines
- Curried regex steps
- Fluent API (sync & async)
- One-liner processors
- Multi-pipeline merge
- Named capture groups support
- Fully typed with TypeScript

## Usage

See examples in `regexPipelineModule.ts` for:

- Sync and async processing
- Multi-pipeline merge
- Fluent API usage
